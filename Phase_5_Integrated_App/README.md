# Phase 5: Full Integrated Web Application

This is the final phase of the project. It combines:

- Differentiable physics (Phase 1)
- Vectorized fleet simulation (Phase 2)
- Interactive Streamlit interface (Phase 3)
- Gradient-based optimization (Phase 4)

## Features
- Tabbed interface with three modes:
  - Single Rocket Simulation
  - Fleet Simulation (vectorized)
  - Gradient Optimization
- Real-time trajectory visualization
- One-click gradient optimization

## How to Run

```bash
chmod +x run.sh
./run.sh
```

Or manually:
```bash
pip install -r requirements.txt
streamlit run app.py
```
