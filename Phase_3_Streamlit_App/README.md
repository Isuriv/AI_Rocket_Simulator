# Phase 3: Streamlit Web Interface

This phase adds a basic web GUI using **Streamlit**.

## What it includes
- Interactive sliders for thrust, torque, and initial conditions
- Real-time trajectory visualization
- Simulation results displayed on the page

## How to Run

```bash
chmod +x run.sh
./run.sh
```

Or manually:

```bash
pip install -r requirements.txt
streamlit run app.py
```
