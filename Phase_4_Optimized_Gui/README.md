# Phase 4: Gradient Optimization + Interactive GUI

This phase adds **gradient-based optimization** directly into the Streamlit web interface.

## Features
- Manual simulation with sliders
- One-click gradient optimization using differentiable physics
- Comparison of results before and after optimization
- Loss curve visualization

## How to Run

```bash
chmod +x run.sh
./run.sh
```

Or manually:
```bash
pip install -r requirements.txt
streamlit run app.py
```
