# Phase 6: Multi-Agent Features

This is the final advanced phase of the project.

## Features
- Multiple rockets (agents) simulated simultaneously
- Each rocket has its own target/goal
- Basic collision avoidance using repulsion forces
- Interactive controls for number of rockets and avoidance strength

## How to Run

```bash
chmod +x run.sh
./run.sh
```

## Notes
This is a simplified multi-agent demonstration. Real multi-agent systems would include more sophisticated behaviors like formation control, communication, and learned policies.
